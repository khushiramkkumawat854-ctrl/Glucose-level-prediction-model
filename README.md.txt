Glucose Prediction using Machine Learning

## 📌 Project Overview

This project predicts glucose levels using Machine Learning techniques.

The complete workflow includes:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Selection
- Train-Test Split
- Feature Scaling
- Model Training
- Model Evaluation
- Model Comparison
- Best Model Selection
- Model Saving
- Prediction

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
